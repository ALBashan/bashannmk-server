# בשן רדיאטורים וחלפים — חנות B2B

موقع B2B لشركة בשן רדיאטורים וחלפים — بيع بالجملة للتجار فقط (مثل bashanrad.com لكن مع إمكانية الشراء).

## הפעלה / التشغيل

```bash
npm install
npm start          # http://localhost:3000
```

- **האתר:** `http://localhost:3000/`
- **פאנל ניהול:** `http://localhost:3000/admin.html`
- **מנהל ראשוני:** `admin@bashan.co.il` / `Bashan2026!` — ⚠️ יש להגדיר `ADMIN_PASSWORD` בסביבת הייצור!

## קטגוריות ומק"טים / الفئات وأرقام المק"ט

לכל מוצר מק"ט ייחודי עם קידומת לפי הקטגוריה:

| קטגוריה | קידומת מק"ט | דוגמה |
|---|---|---|
| רדיאטורים | `RAD` | `RAD-TOY-1001` |
| טורבו | `TRB` | `TRB-HYU-1015` |
| מדחסים | `CMP` | `CMP-KIA-1020` |
| מאווררים | `FAN` | `FAN-MAZ-1008` |
| מעבים | `CND` | `CND-VW-1030` |
| מאיידים | `EVP` | `EVP-REN-1012` |
| אלטרנטורים | `ALT` | `ALT-BMW-1055` |
| סטרטרים | `STR` | `STR-MER-1040` |
| רדיאטור חימום | `RHT` | `RHT-FOR-1025` |
| שסתומים למדחסים ומאיידים | `VLV` | `VLV-NIS-1033` |
| בלוני גז | `GAS` | `GAS-1001` |

בפריטים לפי רכב, החלק האמצעי במק"ט הוא קוד היצרן (TOY = טויוטה, HYU = יונדאי וכו').
הקטלוג נבנה אוטומטית מ־`catalog.js`: **31 יצרני רכב** (פרטי, מסחרי ומשאיות) × דגמים × דורות ≈ **3,850 מק"טים**.

## איך זה עובד B2B / آلية العمل

1. סוחר נרשם בטופס "הרשמת סוחר" (שם עסק, ח.פ, טלפון…) — החשבון נוצר בסטטוס **ממתין**.
2. מנהל מאשר את החשבון בפאנל הניהול.
3. רק סוחר **מאושר** רואה מחירים ויכול לשלוח הזמנות (עם חישוב מע"מ 18%).
4. ההזמנות מגיעות לפאנל הניהול עם ניהול סטטוס (חדשה → בטיפול → נשלחה → הושלמה).

אורחים רואים את הקטלוג המלא (שמות, מק"טים, מלאי) — אבל **בלי מחירים**.

## הגנה משיתוף חשבון / حماية من مشاركة الحساب

כדי למנוע מסוחר להעביר את פרטי הגישה שלו למתחרים:

1. **ישיבה פעילה אחת בלבד לכל חשבון סוחר** — התחברות ממכשיר חדש מנתקת מיידית את המכשיר הקודם, עם הודעה: *"החשבון חובר ממכשיר אחר ולכן נותקת"*. שיתוף חשבון הופך לבלתי-שמיש בפועל (לביטול: `SINGLE_SESSION=0`).
2. **תיעוד מלא של כל התחברות** — מזהה מכשיר, כתובת IP, דפדפן וזמן — נשמר לכל סוחר.
3. **דגל חשד אוטומטי 🚨 בפאנל הניהול** — חשבון שהתחבר מ-3+ מכשירים ב-30 יום או מ-3+ כתובות IP ב-24 שעות מסומן כחשוד לשיתוף.
4. **כפתור "פעילות"** ליד כל סוחר — היסטוריית התחברויות, רשימת מכשירים, וכפתור **ניתוק כל המכשירים** מיידי.

## תכונות נוספות

- 🚗 **חיפוש לפי מספר רכב** — איתור רכב ממאגר משרד התחבורה (data.gov.il) וסינון חלקים לפי היצרן.
- 🔍 סינון לפי קטגוריה / יצרן / דגם + חיפוש חופשי לפי מק"ט או OEM.
- 🛒 סל הזמנה עם כמויות, הערות ומספר הזמנה (`BS-2026-0001`).

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `index.js` | שרת Express — API, אימות, הזמנות, ניהול, איתור רכב |
| `catalog.js` | הגדרת קטגוריות, יצרנים ובניית קטלוג המוצרים |
| `store.js` | שמירת סוחרים והזמנות ב־`data/db.json` |
| `public/` | האתר עצמו (HTML/CSS/JS, עברית RTL) + פאנל ניהול |

הערה: פרטי הקשר באתר (טלפון/כתובת) הם placeholder — יש לעדכן ב־`public/index.html`.
